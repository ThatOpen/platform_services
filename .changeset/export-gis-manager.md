Export `GISManager`, the built-in for Google Photorealistic 3D tiles, vector GIS layers (shapefile and GeoJSON) and the 2D minimap, together with its types and a consumer-facing example. Also adds examples for the GIS, 2D map and GIS properties panels. The package now depends on `@types/geojson`, which the `GISManager` types reference.
